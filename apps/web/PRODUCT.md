# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Product builders evaluating contextual browser interactions and integrating AnyClick into their applications.

## Product Purpose

Turn a selected interface object into useful context, a conversation, and a completed action. The homepage proves the whole journey and provides its implementation recipe.

## Capabilities and Constraints

Four hosted sample applications cover software development, commerce, healthcare administration, and social publishing. AI responses are live. Sample mutations persist within an anonymous 24-hour workspace. GitHub is the only external write integration in this release; its dedicated demo repository is disclosed before submission. Extension changes and visitor account connections are out of scope.

## Brand Commitments

Keep the AnyClick identity and existing industry accents. Use concrete, accurate language. Never represent unavailable services or model output as a completed action.

## Product Principles

- Make selection, included context, and destinations visible.
- Offer a useful next step after every result.
- Keep application facts and mutations deterministic.
- Provide keyboard and touch equivalents for right-click.

## Accessibility & Inclusion

Keyboard operation, editable suggestions, mobile sheets, visible focus, reduced motion, and preserved browser zoom are required.
